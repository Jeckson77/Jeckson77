**OneHub** is an independently developed university-student workspace designed to bring academic planning, university-service shortcuts, and AI study assistance into one responsive interface.

- ☁️ React/Vite frontend and Node.js backend deployed on Render

**Tech:** React · Vite · JavaScript · CSS · Node.js · Supabase · DeepSeek API · Render · GitHub

> Independent student project, not an official UNAM service. University portal SSO and live student-data integrations are not currently available.

### 🎵 Ja Music — Namibian Music Marketplace

<p align="center">
  <a href="https://github.com/Jeckson77/ja-music">
    <img src="https://img.shields.io/badge/GitHub-Ja_Music-181717?style=for-the-badge&logo=github" alt="Ja Music repository" />
  </a>
  <a href="https://ja-music-development.onrender.com/">
    <img src="https://img.shields.io/badge/Explore-Ja_Music_Development-FF2D87?style=for-the-badge&logo=render&logoColor=white" alt="Explore Ja Music development website" />
  </a>
</p>

**Ja Music** is an artist-first music marketplace concept focused on making Namibian music easier to discover, own and support. The proposed platform lets local musicians sell songs and albums directly to fans, with accessible airtime-based payments as a future goal.

**Prototype features and roadmap:**
- 🎧 **Listener experience:** Explore Namibian music, browse releases, search tracks and manage a sample library
- 🎙️ **Artist Studio:** Create local release drafts, propose prices and explore artist business tools
- 🎁 **Fan support:** Interactive song and album purchase, gifting and wallet flows using simulated balances
- 💿 **Music discovery:** Real Namibian artist and release references in the prototype
- 📱 **Design:** Responsive React/Vite website with interactive visual components
- 💸 **Planned:** Licensed music distribution, telecom-integrated airtime payments, secure transactions and verified artist payouts

**Tech:** React · Vite · JavaScript · CSS · GitHub · Render

> **Development-stage project:** Current transactions, wallets, gifting and earnings are simulations. Artist onboarding, licensed audio distribution, real airtime billing and payouts are not live. Featured artists are not represented as platform partners.

**[View Source Code](https://github.com/Jeckson77/ja-music)** · **[Explore Development Website](https://ja-music-development.onrender.com/)**

### ⚛️ Namibia Coastal FPU / Marine SMR — Decision Support Platform

<p align="center">
  <a href="https://github.com/Jeckson77/Namibia-Coastal-FPU-Marine-SMR-Platform"><img src="https://img.shields.io/badge/GitHub-Marine_SMR_Platform-181717?style=for-the-badge&logo=github" alt="Marine SMR project repository" /></a>
  <a href="https://namibia-coastal-fpu-marine-smr.onrender.com"><img src="https://img.shields.io/badge/Render-Open_Platform-00B5AD?style=for-the-badge&logo=render&logoColor=white" alt="Open the Marine SMR platform" /></a>
</p>

An interactive **hackathon decision-support prototype** exploring Floating Power Units (FPUs) and Small Modular Reactors (SMRs) in Namibia's Orange Basin. Designed as a strategic planning and visualization environment for the Rosatom Hackathon, not a licensed or operational nuclear system.

**Project modules:** Geographic hazard mapping, monitoring views, technical review, recommendations, a knowledge-based NARI assistant, and decision-report export.

**Verified repository tools:** React 19 · Vite 6 · JavaScript/JSX · Tailwind CSS 3 · PostCSS · Framer Motion · Leaflet · React Leaflet · Recharts · Lucide React · jsPDF · GitHub · Render

**[Open Platform](https://namibia-coastal-fpu-marine-smr.onrender.com)** · **[Source Code](https://github.com/Jeckson77/Namibia-Coastal-FPU-Marine-SMR-Platform)**
